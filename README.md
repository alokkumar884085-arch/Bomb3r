## Commands
- `/start` - Start the bot
- `/bomb <number>` - Start bombing
- `/stop <number>` - Stop bombing
- `/status` - Your status
- `/credits` - Your credits
- `/redeem <code>` - Redeem code
- `/protect <number>` - Protect number
- `/unprotect <number>` - Remove protection
- `/protected` - Show protected numbers

## Admin Commands
- `/add <user_id> <amount>` - Add credits
- `/remove <user_id> <amount>` - Remove credits
- `/gen <quantity> <credits>` - Generate codes
- `/off` - Turn off bot
- `/on` - Turn on bot
- `/stats` - Bot statistics
- `/logs` - Attack logs
- `/broadcast <msg>` - Broadcast message
- `/users` - Show user count
